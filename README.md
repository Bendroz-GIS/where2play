> [!NOTE]
> Cette application nécessite Node Js <br/> [Lien de téléchargement](https://nodejs.org/en/download)

# Configuration

## Installation des dépendances

```
cd backend
npm install
cd ..
cd frontend
npm install
```

## Lancement de l'application

### Dev

```
cd backend
npm run dev
```

```
cd frontend
npm run dev
```

L'application est accessible à l'url : [http://localhost:5173/](http://localhost:5173/)

### Prod

a configurer dans render

```
cd frontend
npm run build
cd ..
cd backend
npm run start
```
